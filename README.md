# متجر أحلام (Ahlam Store)
> براند مصري راقٍ للحقائب الحريمي الفاخرة | Egyptian Luxury Women's Bags

## ✨ المميزات الرئيسية (Key Features)
1. **سينما الأزياء ومنسق الإطلالات السينمائي (Interactive Lookbook):**
   - استعراض سينمائي لتنسيق الحقائب مع المشاهد والمناسبات المختلفة (Streetwear, Red Carpet Gala, Business, Riviera).
   - عداد ذكي لنسبة التناغم البصري مع نصائح خبراء المظهر.
2. **ستوديو السعة التفاعلي (Inside The Bag Capacity Visualizer):**
   - تجربة تفاعلية تتيح للعميلة معرفة ما إذا كانت متعلقاتها اليومية (آيفون، محفظة، روج، نظارة) تتسع داخل الحقيبة قبل الطلب.
3. **تجربة تسوق مصرية متكاملة:**
   - تصميم متجاوب 100% مع كافة أحجام الشاشات (الهواتف الذكية، التابلت، اللابتوب، والشاشات الكبيرة).
   - خطوط عربية واضحة ومتباعدة بدقة تمنع أي تداخل.
   - إمكانية الطلب المباشر للدفع عند الاستلام مع حق المعاينة قبل الدفع.
   - زر للتواصل والطلب الفوري عبر واتساب (WhatsApp).

## 🚀 طريقة التشغيل (How to Run)
- افتح `index.html` في أي متصفح مباشرة، أو
- شغّل السيرفر المحلي عبر بايثون:
  ```bash
  python server.py
  ```
