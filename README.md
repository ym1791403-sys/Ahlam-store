# متجر أحلام (Ahlam Store)
> براند مصري راقٍ لأفخم الحقائب النسائية الجلدية المصنوعة يدوياً بمواصفات ملكية | Egyptian Haute Maroquinerie

---

## ✦ المميزات الرئيسية (Key Highlights)

1. **الهوية البصرية وشعار البراند الفاخر (Royal Luxury Branding):**
   - تصميم شعار مونوغرام كوتور مذهب مستوحى من كبرى دور الأزياء العالمية (`Champagne Gold` & `Obsidian Noir`).
   - ملفات شعار فيكتور نقية (`assets/logo.svg` و `assets/favicon.svg`).
   - أيقونات متجر محركات بحث جوجل وتبويبات المتصفح (`favicon.ico` متعدد المقاسات).
   - كارت معاينة فاخر عالي الدقة للروابط عند المشاركة على واتساب وفيسبوك وتيليجرام (`assets/og-image.jpg` 1200x630).

2. **دعم التثبيت كتطبيق موبايل (PWA Web App):**
   - إمكانية تثبيت المتجر كتطبيق مستقل على الشاشة الرئيسية لهواتف iPhone (عبر `apple-touch-icon.png`) وهواتف Android (عبر `manifest.json` و `icon-192.png` / `icon-512.png`).
   - دعم التصفح السلس والعمل أوفلاين وسرعة الاستجابة عبر Service Worker (`sw.js`).

3. **سينما الأزياء ومنسق الإطلالات (Cinematic Lookbook):**
   - استعراض سينمائي تفاعلي لتنسيق الحقائب مع المناسبات وأنماط الأزياء المختلفة (Streetwear, Midnight Gala, Power Tailoring, Resort Brunch).
   - عداد ذكي لنسبة التناغم البصري مع نصائح خبراء المظهر.

4. **نظام فحص ومعاينة الشنط وسلة الطلب السلسة:**
   - إمكانية النقر على صورة أو اسم أي حقيبة لفتح نافذة المعاينة السريعة الفورية وفحص الخامات والأبعاد والألوان المتوفرة.
   - حقيبة طلبات عصرية تنزلق بسلاسة بدون أي تجميد أو تعليق، مع زر طلب فوري بالدفع عند الاستلام والمعاينة الكاملة قبل الدفع.
   - زر مباشر للتواصل الفوري والطلب الخاص عبر تطبيق واتساب (WhatsApp Concierge).

5. **أيقونات فيكتور مخصصة (Bespoke Luxury SVG Icons):**
   - واجهة نظيفة 100% خالية من أي إيموجيز كرتونية، معتمدة بالكامل على أيقونات فيكتور رقيقة وخطوط طبوغرافية مذهبة.

## 🚀 طريقة التشغيل والتشغيل المحلي (How to Run)

- افتح ملف `index.html` في أي متصفح مباشرة، أو
- شغّل السيرفر المحلي عبر بايثون:
  ```bash
  python server.py
  ```
- أو عبر ملف التشغيل السريع:
  ```cmd
  start.bat
  ```

## 🛡️ الأمان والخصوصية (Security & Integrity)
- تدقيق دوري ضد الثغرات عبر GitHub Actions (`.github/workflows/security-scan.yml`).
