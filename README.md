# Ahlam Store - VÉRA Bags Studio
> متجر عصري وجريء للحقائب النسائية الفاخرة | Contemporary Avant-Garde Women's Bags E-Commerce

## ✨ المميزات الرئيسية (Key Features)
1. **منسق الإطلالات الذكي (Interactive Lookbook & Outfit Matcher):**
   - تجربة سينمائية لتنسيق الحقائب مع مناسبات وأزياء مختلفة (Streetwear, Gala, Business, Resort).
   - عداد ذكي للتناغم البصري (Synergy Meter) مع نصائح خبراء المظهر.
2. **ستوديو السعة التفاعلي (Inside The Bag Capacity Visualizer):**
   - تجربة تفاعلية تتيح للعميلة معرفة ما إذا كانت متعلقاتها اليومية (آيفون، محفظة، روج، نظارة) تتسع داخل الحقيبة.
3. **استوديو النقش والدمغ الحرفي (Bespoke Monogramming Studio):**
   - معاينة حية فورية لنقش الحروف الأولى بالذهب الملكي والبلاتين الفضي والحفر الغائر.
4. **أجواء الإضاءة التفاعلية (Ambient Lighting Studio):**
   - تغيير الهوية اللونية للمتجر بلمسة زر (Solar Tangerine, Cyber Lilac, Neon Lime, Cyber Cyan).
5. **تجربة تسوق متكاملة:**
   - ثنائي اللغة بالكامل (عربي RTL / إنجليزي LTR).
   - تحويل العملات تلقائياً (SAR, AED, EGP, USD).
   - حقيبة تسوق منبثقة (Cart Drawer) مع كود خصم وشحن مجاني.

## 🚀 طريقة التشغيل (How to Run)
- افتح `index.html` في أي متصفح مباشرة، أو
- شغّل السيرفر المحلي عبر بايثون:
  ```bash
  python server.py
  ```
